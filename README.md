# xyt mobile

PC의 xyt digest가 모은 X 코멘트·블로그·X 요약·유튜브 요약을 휴대폰에서 보는 PWA.

- 데이터: Supabase (토큰으로 잠긴 RPC 함수만 호출, 테이블 직접 접근 불가)
- 접속: PC xyt digest → ⚙ → **휴대폰 앱** → QR 스캔 → Chrome 메뉴 "앱 설치/홈 화면에 추가"
- 접속 키는 기기 localStorage에만 저장됩니다. 링크/QR을 다른 사람과 공유하지 마세요.
- 분류(주식/FICC/기타)를 휴대폰에서 바꾸면 다음 PC 동기화 때 PC에도 반영됩니다.
